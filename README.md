\# CodeAlpha Python Programming Internship Tasks



This repository contains Python solutions developed for the \*\*CodeAlpha Python Programming Internship\*\*.



\---



\## 📁 Repository Structure



\* \*\*`task1\_hangman.py`\*\*: A text-based Hangman game featuring secret word selection, letter guessing logic, and attempt tracking.

\* \*\*`task2\_stock\_tracker.py`\*\*: A financial tool that calculates total portfolio investment value based on user inputs and exports summary reports (`.txt` or `.csv`).

\* \*\*`task3\_file\_automation.py`\*\*: A file management automation script using `os` and `shutil` modules to organize `.jpg` images automatically.

\* \*\*`task4\_chatbot.py`\*\*: A rule-based conversational chatbot implemented using conditional structures and functions.
